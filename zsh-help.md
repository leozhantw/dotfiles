# Zsh Keybindings & Features

## Keybindings

| Key | Description |
|-----|-------------|
| `↑` / `↓` | History prefix search |
| `Ctrl+R` | Fzf history search |
| `Ctrl+←` / `Ctrl+→` | Jump word |
| `Tab` | Case-insensitive completion (menu select) |

## Options

| Option | Description |
|--------|-------------|
| `AUTO_CD` | Type dir name to cd |
| `HIST_IGNORE_DUPS` | No consecutive duplicates |
| `HIST_IGNORE_SPACE` | Space prefix = no history |

## Aliases

| Alias | Description |
|-------|-------------|
| `reload` | Reload zshrc |
| `zshhelp` | Show this help |
| `ls` / `l` / `ll` / `la` | Eza variants |
| `cat` | Bat |
| `kc` | kubectl |
| `kcx` | kubectx |
| `kcns` | kubens |
| `kcsh <pod>` | kubectl exec into pod |
| `ghclear` | Clean merged branches |
| `ghbr` | Fzf branch switch |
